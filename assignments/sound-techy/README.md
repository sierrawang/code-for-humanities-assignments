# Sound Techy
Have you ever wanted to sound like a technology expert, but not known the jargon? Fear not! This assignment will give you the information you need to sound like you are a technology genius!

Challenge:
Use the ["Techy API"](https://techy-api.vercel.app/) to generate a random techy term, then print it out to the console.

The endpoint that you will request is:
`https://techy-api.vercel.app/api/json`

The API returns a random techy term each time. Open the link in your browser to see the JSON structure of the response. Then, write code that makes a request to this endpoint and prints the term to the console.
