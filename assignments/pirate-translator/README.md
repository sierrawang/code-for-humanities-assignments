# Pirate Translator
Using the OpenAI API, create a program that accepts a phrase from a user and translates it into pirate speak.

Here is some sample output from the solution program:
```
Enter the English text to translate to pirate speak: Hi there, how are you today?
Pirate Translation: Ahoy matey! How be ye this fine day?
```


# Optional Extension
Try allowing the user to select the persona of the translation. Here is an example:

```
Enter the type of translation (e.g., 'pirate', 'Shakespeare'): Shakespeare
Enter the English text to translate to Shakespeare speak: Hi there, how are you today?
Shakespeare Translation: Good morrow! How art thou this fine day?
```
