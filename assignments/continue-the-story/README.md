# Continue the Story
In this challenge, you will create a chatbot that can work with the user to create a story. Use the "developer" role to prompt the API to alternate with the user, writing one sentence at a time.

An example output of the program might look like this:
```
Start the story: There once was a pig named "Bob" from Rhode Island.
The story continues: Bob was no ordinary pig; he dreamed of becoming a master chef and opening his own restaurant.
Continue the story: He always heard people discussing this magical place called "Cranston" where the food was great!
The story continues: Determined to find this culinary paradise, Bob decided to embark on an adventure to Cranston.
Continue the story: He took the RIPTA bus, and ended up in Pawtuxet Village!
The story continues: Confused but undeterred, Bob wandered through the quaint streets, hoping to discover a hidden gem of a restaurant.
Continue the story: It was there that he found some delicious food!
The story continues: The aroma of freshly baked bread and sizzling vegetables wafted through the air, leading him to a cozy little bistro called "The Green Fork."
Continue the story: ...
```

Note that there is a prompt that goes unseen by the user in the output.
