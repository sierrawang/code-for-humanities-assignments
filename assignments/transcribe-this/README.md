# Transcribe This
In this assignment, you have been given three images of text. Your task is to use the OpenAI API to transcribe the text from these images into a single text file.

Use the response API and pass in the images as input, with a prompt instructing the model to transcribe the text from the images. See how the model handles different texts. Once you have the "transcriptions", save them in a text files for each image.

We also encourage you to experiment with your own images and see how well the model performs on them.
